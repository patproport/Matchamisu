Every APK license asset is byte-identical to its source-tree counterpart, as is the in-app notice. No ZIP entry name matching removed typing OGG or Titan caption-bar images was found. The 98 resolved artifacts include metadata/placeholder modules; the SBOM is not proof that each POM or library file is copied as a standalone APK entry. Bazel, NDK, protoc, Docker image and Gradle plugins are build tools, not application components.

The PSL source-form question is resolved in the public `THIRD_PARTY_NOTICES.md`: the APK's gzip matches OkHttp's 4.11.0 tag and Maven JAR byte for byte; the tag's source `public_suffix_list.dat` matches official Public Suffix List commit `a312abe0e11421aff8fe909a5e02f36b7c5d28de` byte for byte; all 9,499 ordinary/wildcard and eight exception rules match the APK's decoded blocks. The gzip discards comments, so its generating process cannot be proven to have read that precise text file solely from rule equality. The fixed source and MPL-2.0 URL are now in the public NOTICE. The linked Abseil/protobuf/zlib/`utf8_range` project licenses and copyright texts are bundled; no additional specific upstream NOTICE file has been demonstrated as missing. The 98 POM entries do not imply 98 separate NOTICE files. Additional artifact-level provenance can be improved without assuming a missing legal notice. Compare the exact staged source set with the APK before publication.
